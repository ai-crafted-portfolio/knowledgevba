# DEMO-0001 - サービス復旧手順（新入力型デモ）

**配置先**: `C:\KnowledgeMgr\data\DEMO-0001.txt`

メモ帳で **ANSI** (Shift-JIS) として保存してください。改行は CRLF。

## 「手順書」欄（リッチ型）の記法

3 種類とも **開始と終了で囲む** 同じ書き方です。登録画面の
［ブロック］／［見出し］／［太字］ ボタンを押すと、選択した行がこの形で囲まれます。

| 要素 | 書き方 |
|---|---|
| 見出し（大きい太字） | `【見出し】` 〜 `【見出しここまで】` |
| 太字の段落 | `【太字】` 〜 `【太字ここまで】` |
| コピーボタン付きブロック | `【ブロック】` 〜 `【ブロックここまで】` |

## 「添付」欄（ファイル（リンク）型）

1 行に 1 件。**ローカルのファイルパスでも、Box などの https URL でも構いません**。
登録画面では ［ファイル選択］（ローカル）と ［URL追加］（Web リンク）で追加できます。
表示画面では 1 件ごとに ［開く］ が付き、ローカルは既定アプリ、URL は既定ブラウザで開きます。

概要
