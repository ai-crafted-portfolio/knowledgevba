# DEMO-0001 - サービス復旧手順（新入力型デモ）

**配置先**: `C:\KnowledgeMgr\data\DEMO-0001.txt`

メモ帳で **ANSI** (Shift-JIS) として保存してください。改行は CRLF。

「手順書」欄はリッチ型です。記法は次の 3 つで、いずれも **行単位**で書きます。

| 見た目 | 書き方 |
|---|---|
| 見出し（大きい太字） | 行頭に `【見出し】` を付ける |
| 太字の段落 | 行頭に `【太字】` を付ける |
| コピーボタン付きブロック | `【ブロック】` と `【ブロックここまで】` で囲む |

> 登録画面では ［ブロック］／［見出し］／［太字］ ボタンを押すと、選択した行に
> この記法が自動で入ります。手で書いても同じです。

```text
###formatId###
DEMO
###件名###
サービス復旧手順（新入力型デモ）
###手順書###
【見出し】 概要
【太字】 作業前に責任者の承認が必要です。
本番サービスが停止したときの復旧手順です。
【見出し】 コマンド
以下を順に実行してください:
【ブロック】
sudo systemctl stop app
sudo systemctl start app
tail -f /var/log/app.log
【ブロックここまで】
【見出し】 確認
ヘルスチェックが 200 を返すこと。
###定型コマンド###
sudo systemctl status app
journalctl -u app --since "1 hour ago"
###添付###
C:\KnowledgeMgr\dist\管理.xlsm
C:\KnowledgeMgr\dist\検索.xlsm
###確認者###
山田 太郎
```
