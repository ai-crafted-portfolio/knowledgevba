# M-09 ナレッジ表示

`ナレッジ表示` 画面(フォーム)の設定ファイルです。ファイルが無い場合は既定のレイアウトで表示されます(動作には支障ありません)。フォームの寸法・フォント・タイトルを変えたいときに配置してください。

## 配置先

以下のパスに **そのままのファイル名で** 配置してください。

```text
C:\KnowledgeMgr\ui\検索\M-09.txt
```

## 保存手順

1. 下の **内容** を全選択してコピー (右上のコピーボタンが便利)
2. **メモ帳** を開いて貼り付け
3. 「ファイル」 → 「名前を付けて保存」
4. ファイル名を `M-09.txt` にする
5. **文字コードを「ANSI」(Shift_JIS) に変更** ← 重要
6. 改行コードは「CRLF」(Windows 標準) のままにする
7. 上記 **配置先** のパスに保存

> 文字コードを UTF-8 のままにすると、画面タイトルや項目名が
> **文字化け** します。必ず `ANSI` で保存してください。

## 内容

```ini
[USERFORM]
formWidth=486
formHeight=0
fontName=メイリオ
fontSize=10
labelWidth=107
rowHeightSingle=48
rowHeightMulti=114
rowHeightMultiLong=129
margin=18
buttonBarHeight=48
caption=ナレッジ表示
multiLineScrollBars=vertical
===
```
