# 登録・編集の流れ

入力から保存・反映までを、ひとつながりで説明します。

## 登録のひとつながりの流れ

1. **型を選ぶ** — 登録画面でフォーマット（型）を選ぶと、その型の入力欄が画面に展開されます。
2. **内容を入力する** — 展開された各項目に入力します（必須項目は空のままだと登録できません）。
3. **登録する** — 『登録』ボタンを押すと、内容が 1 件のナレッジとして保存されます。
4. **結果を確認する** — ナレッジ番号が表示され、以降は検索で見つけられるようになります。

!!! tip "保存の仕組み"
    保存されたナレッジは `data` フォルダに 1 件 1 ファイルで残ります。

## 入力のコツ

- 必須の項目には印が付いています。空のままだと登録できないので、まず必須から埋めます。
- 日付の項目は『2026/06/17』のように、年／月／日をスラッシュで区切って入力します。
- 複数行の欄で改行したいときは、そのまま `Enter` キーを押します（改行が入ります）。
- 型に合わない値（数値欄に文字など）は登録時に知らせてくれるので、表示に従って直します。

!!! tip "読み手に親切な書き方"
    あとから見返す人のために、タイトルは具体的に。検索のヒット率が上がります。

## 既存ナレッジを直す・消す

1. **ナレッジ番号で読み込む** — 登録画面でナレッジ番号（例：FAULT-0001）を入れ、『読込』を押します。
2. **内容を編集する** — 読み込んだ項目を直し、『更新』を押すと修正が保存されます。
3. **不要なら削除する** — 削除する場合は『削除』を押し、確認に『はい』で消します。

!!! tip "安心ポイント"
    修正・削除のときは、変更前の内容が `backup` フォルダに自動で控えとして残ります。

## 入力欄に付くボタン

フォーマットの型によって、入力欄のそばにボタンが出ます。押し方は次のとおりです。
（型そのものの説明は[フィールド型の説明](types.md)を参照してください。）

| ボタン | 出る場所 | 押すと |
|---|---|---|
| ［ブロック］［見出し］［太字］ | 複数行（リッチ）の欄の上 | カーソルのある行（選択中ならその範囲）を装飾の記法で囲みます |
| ［ファイル選択］ | ファイル（リンク）の欄の上 | ファイル選択ダイアログが開き、選んだファイルのパスが 1 行 1 件で追加されます（`Ctrl` で複数選択可） |
| ［URL追加］ | ファイル（リンク）の欄の上 | アドレスの入力を求められます。`https://` から始まるリンクを貼って『OK』を押すと 1 行追加されます |
| ［コピー］ | 表示画面（複数行（コピー）の項目名の右／リッチのコード枠の右上） | その内容をクリップボードにコピーします |
| ［開く］ | 表示画面（ファイル（リンク）の 1 件ごと） | ローカルのファイルは既定のアプリ、URL は既定のブラウザで開きます |

## 保存する前に仕上がりを見る（［表示］）

複数行（リッチ）またはファイル（リンク）の項目を含むフォーマットでは、
登録・編集画面の下に **［表示］** ボタンが出ます。

1. 一通り入力します（まだ登録しなくてかまいません）。
2. **［表示］** を押します。いま入力中の内容が、検索結果から開いたときと同じ見た目で別ウィンドウに表示されます。
3. 見出しやコード枠の見え方を確認します。直したいところがあれば、ウィンドウを閉じて入力に戻ります。
4. 問題なければ『登録』（編集中なら『更新』）を押します。

!!! note "ウィンドウの大きさ"
    表示ウィンドウは、右上の最大化ボタンのほか、**ウィンドウの端をドラッグ**しても大きさを変えられます。

## Word / Excel に書き出す

登録したナレッジは、Word 文書や Excel 一覧として書き出せます。
**［Word出力］［Excel一覧］** の 2 つのボタンは、次の 2 か所に出ます。

- 検索結果からナレッジを表示したウィンドウ
- 登録・編集画面の **［表示］** で開いたプレビューウィンドウ（**まだ保存していない内容でも書き出せます**）

**利用者がすること**

1. 書き出したいナレッジを表示します（検索結果をダブルクリック、または登録画面で［表示］）。
2. **［Word出力］** を押すと、そのナレッジ 1 件が 1 つの Word 文書になります。
   **［Excel一覧］** を押すと、**同じフォーマットの全ナレッジ**が 1 枚の一覧表になります。
3. 出来上がったファイルは **自動的に開きます**。保存先は次の固定フォルダです。

    ```
    C:\KnowledgeMgr\export\
    ```

4. 別の場所に置きたいときは、開いた Word / Excel で『名前を付けて保存』するか、
   エクスプローラーで上のフォルダから移動してください。

**書き出しの中身**

| 出力 | ファイル名 | 中身 |
|---|---|---|
| Word | `ナレッジ番号_件名_日時.docx` | ナレッジ 1 件。見出しは太字、リッチのコード枠は等幅＋灰色の網かけ、ファイル（リンク）はクリックできるリンクになります |
| Excel | `フォーマットID_一覧_日時.xlsx` | そのフォーマットの全ナレッジ。1 行 1 ナレッジ。列は ナレッジ番号／登録日／更新日＋フォーマットの全項目。見出し行にオートフィルタが付きます |

!!! warning "事前に必要なもの"
    - **［Word出力］には Word、［Excel一覧］には Excel が必要です。** 入っていない場合はメッセージが出て中止されます。
    - 出力フォルダ `C:\KnowledgeMgr\export\` は、最初の書き出しのときに自動で作られます。事前の作成は不要です。
    - ボタンは連打しないでください（書き出しが終わるまで次の操作は受け付けません）。
    - Excel の一覧では、リッチの記法（`【見出し】` など）は取り除かれ、読みやすい素の文章で入ります。
