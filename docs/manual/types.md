# フィールド型の説明

フォーマットの「項目（フィールド）」には、入力する内容に合わせて **型** を指定します。
型によって、入力欄の見た目（1 行か、複数行か、カレンダーか、選択肢か）と、保存される値の形が決まります。

このページでは、設計画面で選べる型と、各項目に設定できる属性をすべて説明します。

## 設計画面で選べる型

フォーマット設計画面の「型」の欄では、次の 9 種類から選べます。

| 設計画面で選ぶ型 | 入力欄の見た目 | 主な用途 | 入力例 |
|---|---|---|---|
| 1 行テキスト | 1 行の入力欄 | 件名・担当者名など短い文字列 | 経理システムへログインできない |
| 複数行テキスト | 改行できる広い入力欄 | 概要・原因・対応内容など長い文章 | 応答時間が通常の 10 倍以上に増加 |
| 複数行（コピー） | 広い入力欄。表示画面では欄ごと［コピー］できる | コマンド・定型文など、まるごと貼り付けて使う内容 | sudo systemctl status app |
| 複数行（リッチ） | 広い入力欄＋［ブロック］［見出し］［太字］の 3 ボタン | 手順書・調査メモなど、見出しやコード例を含む長文 | （下の「リッチの書き方」を参照） |
| ファイル（リンク） | 広い入力欄＋［ファイル選択］［URL追加］。表示画面では 1 件ごとに［開く］ | 手順書 PDF、Box や SharePoint の共有リンク | C:\手順\復旧手順.pdf |
| 数値 | 1 行の入力欄 | 件数・金額・回数など数字 | 120 |
| 日付 | 日付を入れる入力欄 | 発生日時・対応日など | 2026-06-09 |
| 選択 | 一覧から 1 つ選ぶ欄 | カテゴリ・優先度など決まった候補から選ぶ項目 | 高 |
| チェック | チェックの有無を選ぶ欄 | 「対応済み」など 2 択の項目 | （チェックあり） |

## 保存される型は 7 種類

設計画面では 9 種類から選べますが、保存されるときには次の **7 種類** に整理されます。
入力欄の見た目はそのままで、内部的にまとめて扱われるだけなので、使い方を意識する必要はありません。

| 設計画面で選ぶ型 | 保存される型 |
|---|---|
| 1 行テキスト | 単一行 |
| 数値 | 単一行 |
| 複数行テキスト | 複数行 |
| 複数行（コピー） | 複数行コピー |
| 複数行（リッチ） | 複数行リッチ |
| ファイル（リンク） | ファイルリンク |
| 日付 | 日付 |
| 選択 | 選択 |
| チェック | 選択 |

- **数値** は「単一行」として保存されます。入力欄は 1 行テキストと同じで、数字を入れる用途の目印として使います。
- **チェック** は「選択」として保存されます。

!!! note "保存後に型を見直したとき"
    「数値」「チェック」を保存したあと、設計画面で開き直すと、それぞれ「1 行テキスト」「選択」として表示されます。
    入力欄の動きは変わらないため、そのまま使えます。

## 各型のくわしい説明

### 単一行（1 行テキスト・数値）

- **入力欄**：1 行の入力欄です。
- **用途**：件名、担当者名、件数、金額など、短い文字列や数字に向きます。
- **文字数の上限**：項目の「最大文字数」で制限できます（後述の属性一覧を参照）。

### 複数行

- **入力欄**：改行できる広い入力欄です。
- **用途**：概要・原因・対応内容など、長めの文章に向きます。
- **行数**：項目の「行数」で入力欄の高さを指定できます。
- **スクロール**：項目の「スクロール」を有効にすると、行数を超える長文も欄内でスクロールして入力できます。

!!! note "スクロールバーの表示（2026-06-25 改善）"
    複数行欄のスクロール挙動を見直しました。動作の違いは次のとおりです。

    - **`TRUE`（スクロールあり）**：入力欄を専用の枠で包み、**垂直スクロールバーを常時表示**します。欄が空のときでもバーが見えるため、「ここはスクロールできる欄だ」と一目で分かります。文字を入力すると欄の内容が伸び、カーソル位置に追従してスクロールします。
    - **`FALSE`（スクロールなし）**：**スクロールバーは表示されません**。行数で指定した高さの固定欄になります。

    既定は `FALSE`（バー無し）です。長文を入力する欄には `TRUE` を指定してください。

### 複数行（コピー）

- **入力欄**：改行できる広い入力欄です。入力のしかたは「複数行テキスト」と同じです。
- **表示画面**：項目名の右に **［コピー］** ボタンが出ます。押すと、その項目の中身が**まるごと**クリップボードにコピーされます。
- **用途**：実行コマンド、定型の連絡文など、そのまま貼り付けて使う内容に向きます。

**利用者がすること**

1. 登録画面で、その欄にコマンドや定型文をそのまま入力します（記法は不要です）。
2. 使うときは、検索結果からナレッジを表示し、項目名の右の［コピー］を押します。
3. 貼り付け先（ターミナル、メールなど）で `Ctrl` + `V` を押します。

### 複数行（リッチ）

見出し・太字・コピーできるコード枠を含む長文を書ける欄です。
入力欄の上に **［ブロック］［見出し］［太字］** の 3 つのボタンが並びます。

**利用者がすること（装飾の付け方）**

1. 装飾したい行にカーソルを置きます（複数行なら、その範囲を選択します）。
2. ［見出し］［太字］［ブロック］のいずれかを押します。選んだ行が下の記法で囲まれます。
3. 仕上がりを確かめるときは、画面下の **［表示］** ボタンを押します（プレビューが別ウィンドウで開きます）。
4. 問題なければ『登録』または『更新』を押します。

**リッチの書き方（記法）**

ボタンは下の記法を入れるだけなので、手で書いても同じ結果になります。**3 種類とも「囲む」書き方**で統一されています。

| 付けたい装飾 | 書き方 |
|---|---|
| 見出し | `【見出し】` と `【見出しここまで】` で挟む |
| 太字の段落 | `【太字】` と `【太字ここまで】` で挟む |
| コピーできるコード枠 | `【ブロック】` と `【ブロックここまで】` で挟む |

記入例:

```
【見出し】
概要
【見出しここまで】
【太字】
作業前に責任者の承認が必要です。
【太字ここまで】
本番サービスが停止したときの復旧手順です。
【ブロック】
sudo systemctl stop app
sudo systemctl start app
【ブロックここまで】
```

**表示画面での見え方**

- 見出し … 大きめの太字で表示されます。
- 太字 … 太字の段落で表示されます。
- ブロック … 等幅フォントの枠で表示され、枠の右上に **［コピー］** が付きます。押すとその枠の中身だけをコピーできます。

!!! warning "記法で気をつけること"
    - 囲みの記号は**全角の角かっこ**（`【` `】`）です。半角の `#` を並べた `###ブロック###` のような書き方はしないでください。ナレッジの保存形式で使っている区切り記号と同じ形になり、その行から先が保存されません。
    - 開始と終了は**それぞれ独立した行**に置きます（ボタンで付ければ自動的にそうなります）。
    - 装飾を入れ子にすることはできません。すでに囲まれている場所でボタンを押しても、二重には囲みません。

### ファイル（リンク）

ファイルの**場所（パス）や URL だけ**を保存する欄です。ファイルの実体はコピーされないので、ナレッジの保存容量は増えません。

**利用者がすること**

1. 登録画面で **［ファイル選択］** を押し、ダイアログでファイルを選びます（`Ctrl` を押しながらで複数選択できます）。選んだファイルの絶対パスが 1 行 1 件で追加されます。
2. Box や SharePoint のような Web のリンクを入れるときは **［URL追加］** を押し、`https://` から始まるアドレスを貼り付けて『OK』を押します。
3. 直接キーボードで書いてもかまいません（1 行に 1 件）。
4. 表示画面では 1 件ごとに **［開く］** ボタンが出ます。押すと、ローカルのファイルは**既定のアプリ**で、URL は**既定のブラウザ**で開きます。

!!! note "扱えるリンクの種類"
    - ローカルのパス（`C:\手順\復旧手順.pdf`）、共有フォルダの UNC パス（`\\server\share\file.xlsx`）、
      `http` / `https` / `ftp` / `ftps` / `mailto` / `file` で始まる URL が使えます。
    - `javascript:` など、それ以外の書き出しは安全のため開きません。
    - ［開く］は連打しても 1 回しか動きません（開き終わるまで、および完了後 1.5 秒は受け付けません）。
    - **リンクなので、元のファイルを移動・削除すると開けなくなります。** 共有フォルダなど、動かない場所に置いてから登録してください。

### 日付

- **入力欄**：日付を入れる欄です。
- **用途**：発生日時、対応日など。
- **入力例**：`2026-06-09` や `2026-06-09 10:30` のように入力します。

### 選択（選択・チェック）

- **入力欄**：あらかじめ用意した候補から 1 つ選ぶ欄です。
- **用途**：カテゴリ、優先度など、決まった候補から選ぶ項目に向きます。
- **候補の指定**：項目の「選択肢」に候補を縦棒 `|` で区切って並べます（例：`低|中|高|緊急`）。

## 項目に設定できる属性

フォーマットの各項目には、型のほかに次の属性を設定できます。
これらはフォーマット定義ファイルに保存されます（書式は[外部設定ファイル](config.md)のページを参照）。

| 属性 | 意味 | 設定できる値 | 既定の扱い | 例 |
|---|---|---|---|---|
| 項目名 | 入力欄に表示される名前 | 任意の文字列 | （必須） | 件名 |
| 型 | 入力欄の種類 | 単一行 / 複数行 / 複数行コピー / 複数行リッチ / ファイルリンク / 日付 / 選択 | （必須） | 単一行 |
| 必須 | 入力を必須にするか | `TRUE`（必須）／ `FALSE`（任意） | `FALSE`（任意） | TRUE |
| 最大文字数 | 入力できる文字数の上限 | 数字（単一行で使用） | 指定なし＝上限なし | 120 |
| 行数 | 複数行系のときの入力欄の高さ | 数字（複数行／複数行（コピー）／複数行（リッチ）／ファイル（リンク）で使用） | 指定なし＝標準の高さ | 4 |
| スクロール | 複数行で欄内スクロールを使うか | `TRUE` ／ `FALSE` | `FALSE` | TRUE |
| 選択肢 | 選択のときの候補 | 候補を縦棒 `\|` で区切って並べる | 指定なし | 低\|中\|高\|緊急 |
| 入力例 | 入力欄に薄く表示する見本 | 任意の文字列 | 指定なし | （例）山田 太郎 |
| 検索対象 | 検索で本文として探すか | `TRUE` ／ `FALSE` | `FALSE` | TRUE |

!!! tip "真偽を表す値の書き方"
    「必須」「スクロール」「検索対象」のように 2 択で指定する項目は、すべて大文字で `TRUE` または `FALSE` と書きます。

## 型の選び方のヒント

- 短い 1 行の入力なら **1 行テキスト**、長い文章なら **複数行テキスト** を選びます。
- そのまま貼り付けて使う内容（コマンド・定型文）は **複数行（コピー）** にすると、表示画面から 1 押しでコピーできます。
- 見出しや手順・コード例が混ざる長文は **複数行（リッチ）** にすると、読みやすく整理できます。
- 手順書 PDF や共有リンクを添えたいときは **ファイル（リンク）** を使います。本文に長い URL を貼るより見やすくなります。
- カテゴリや優先度のように候補が決まっているなら **選択** にすると、入力のばらつきを防げます。
- 検索でよく使う項目は「検索対象」を `TRUE` にしておくと、その内容で絞り込めます。
